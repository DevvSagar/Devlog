## ✨ Features & Architecture

- **Server-Side Rendering & Templating**: Dynamic, fast UI rendering with **Jinja2** templates integrated into FastAPI.
- **Relational Data Management**: Asynchronous **PostgreSQL** with SQLAlchemy ORM and Alembic schema migrations.
- **Cloud Media Storage (AWS & Boto3)**: Media asset uploads and management using **AWS S3** powered by **Boto3**.
- **Role-Based Access Control (RBAC)**: Secure access policies and authorization levels for users and administrators.
- **Containerized Infrastructure**: Streamlined local and production workflows with **Docker** and Docker Compose.
- **Production Reverse Proxy & SSL/TLS**: High-performance request handling with **Nginx** and encrypted HTTPS via **SSL/TLS**.
- **Automated Testing Suite**: Unit and integration test coverage implemented using **Pytest**.
